Pre-Requisite: Participated: Lập trình Java 4
Description: Lập trình Java 5 là môn học lập trình web Spring Boot MVC. Đây là môn học xây dựng ứng dụng web trên nền tảng của một framework công nghệ Java tốt nhất và phổ biến nhất hiện nay.
Một cách tổng quan môn học cung cấp cho sinh nhiên những nội dung sau:
1. Spring Introduction & Spring Boot HelloWorld
2. Request Mapping & Data Sharing and Mapping method result
3. Form and Databinding & Validation
4. Layout & Internationalization
5. Spring Beans
6. JpaRepository
7. Schedule Tasks & Interceptor
